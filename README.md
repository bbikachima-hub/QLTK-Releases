# QLTK cho PC và VPS

Kho phát hành QLTK. Các gói dành cho khách hàng nằm trong [Releases](https://github.com/bbikachima-hub/QLTK-Releases/releases).

## Cài lần đầu

Tải gói Portable, giải nén vào thư mục riêng rồi mở `QLTK.exe`. Nhập key còn hạn để kích hoạt. Giữ nguyên dữ liệu tài khoản/config của mình; không chia sẻ chúng trên GitHub.

## Cập nhật từ phiên bản hỗ trợ GitHub

Mở **Tài khoản → Cập nhật**. Tool kiểm tra bản ổn định mới nhất trên GitHub, tải và xác minh gói trước khi thay chương trình. Xác nhận cập nhật sẽ thoát QLTK và dừng các client do QLTK quản lý; nên thực hiện sau khi các hoạt động kết thúc.

Key chỉ dùng để kích hoạt, không dùng để tải bản cập nhật. Tài khoản, config, key và client Unity được giữ lại. Khi thành công, bộ cập nhật dọn cache và bản sao hoàn tác của lần cập nhật đó.

Nếu mất mạng, gói sai mã kiểm tra hoặc ổ đĩa thiếu chỗ, chưa áp dụng bản mới. Nếu thay file thất bại, bộ cập nhật cố khôi phục các file đã thay và ghi lỗi vào `logs/update-error.txt`.

## Lưu ý

Không tải file chạy từ bình luận hoặc nguồn lạ. Không đăng mật khẩu tài khoản game, key kích hoạt, dữ liệu quản trị hay thông tin proxy lên kho này.
